2. 최근 3개년 출제 경향

2023·2024·2025년 시험 모두 로직은 5문항이었고, 이탈리아 의대 입시(CINECA)식 논리 문제 성격이 뚜렷합니다. 출제 유형은 크게 아래 세 묶음으로 반복됩니다.

유형 묶음세부 유형비중(체감)
A. 형식 논리
(Critical thinking)		명제의 부정, 필요·충분조건(only if, unless), 대우, 삼단논법·집합 관계, 결론 도출, 논증의 가정·약화·오류 찾기높음
B. 수리 문제해결
(Problem solving)		비율·퍼센트, 속력·작업량, 나이, 요일·시간 계산, 확률, 경우의 수, 단위 환산(약물 용량 등 의학 맥락)높음
C. 패턴·배열수열·문자열 규칙, 코딩, 자리 배치·순서 추론, 진실/거짓 퍼즐, 표·자료 해석중간

3. 유형별 핵심 풀이법

① 명제의 부정 (Negation)

원래 명제올바른 부정
All X are Y (모든 X는 Y)At least one X is not Y (적어도 하나는 Y가 아님)
Some X are Y (어떤 X는 Y)No X is Y (어떤 X도 Y가 아님)
P and Qnot P or not Q
P or Qnot P and not Q
If P then QP and not Q

함정: “All X are Y”의 부정을 “No X is Y”로 고르게 만드는 선택지. 부정은 최소한의 반례입니다.

② 조건문 4종 세트 (If / Only if / Unless)

  • If P, then Q → P → Q (P는 충분조건, Q는 필요조건)
  • Q only if P → Q → P (only if 뒤가 화살표의 끝)
  • P unless Q → not Q → P (unless = “if not”)
  • P if and only if Q → 양방향

항상 참인 것은 대우(¬Q → ¬P)뿐입니다. 역(Q → P)과 이(¬P → ¬Q)는 참이 보장되지 않습니다.

③ 삼단논법 · 집합

  • 무조건 벤 다이어그램을 그립니다. “All”은 원 안의 원, “No”는 떨어진 원, “Some”은 겹치는 원.
  • “must be true” 문제는 반례를 하나라도 그릴 수 있으면 오답입니다.
  • 두 집합 개수: |A∪B| = |A| + |B| − |A∩B|, 전체 = 합집합 + 둘 다 아님.

④ 논증 분석 (가정 · 약화 · 강화 · 오류)

  • 먼저 결론을 찾으세요(therefore, so, hence 뒤). 그다음 근거와 결론 사이의 빈틈이 가정입니다.
  • 약화: 대체 원인, 교란변수, 표본 편향, 역인과를 제시하는 선택지. 강화: 대체 원인을 제거하는 선택지.
  • 자주 나오는 오류: 상관 → 인과, 성급한 일반화, 역(逆)의 오류, 필요/충분 혼동, 권위에 호소, 순환 논증.
  • 함정: 사실이지만 논증과 무관한 선택지(“WHO가 권장한다” 등).

⑤ 수리 문제해결

  • 연속 퍼센트: 더하지 말고 곱하기. +20% → −20% = 1.2 × 0.8 = 0.96.
  • 작업량: 시간당 처리량을 더함. 1/T = 1/a + 1/b. 답은 가장 빠른 사람보다 짧아야 합니다.
  • 평균 속력: 총거리 ÷ 총시간. 같은 거리 왕복이면 2ab/(a+b).
  • 나이·방정식: 선택지를 직접 대입하는 것이 대체로 더 빠릅니다.
  • 요일: 날짜 차이 mod 7. 30일 달 → +2, 31일 달 → +3, 평년 → +1, 윤년 → +2.
  • 확률: 비복원추출이면 분모·분자가 하나씩 줄어듭니다. “적어도 하나”는 1 − P(하나도 없음).
  • 의학 맥락 단위: mg/kg/day → 체중을 곱하고, 투여 횟수로 나누는 단계를 빼먹지 않기.

⑥ 배열 · 진실/거짓 퍼즐

  • 고정 정보(“C는 3번 자리”)부터 표에 적고, 다음으로 제약이 가장 강한 조건을 적용합니다.
  • 남은 경우를 2~3개로 나눠 경우 분할 → 모순이 나는 가지를 지웁니다.
  • 진실/거짓: “X가 거짓말쟁이라면?”을 사람마다 가정해 보고, 모순이 없는 경우 하나만 남깁니다.

⑦ 수열 · 코딩

  1. 차이(1차, 2차)를 구한다 → 2. 비율(×, ÷)을 확인한다 → 3. n², n(n+1), 2ⁿ±1 같은 친숙한 수를 찾는다 → 4. 홀수 번째·짝수 번째 항을 따로 본다.
  2. 문자 수열은 알파벳을 숫자로 바꿉니다(A=1 … Z=26). 자주 쓰는 값: E=5, J=10, O=15, T=20.

4. 실전 전략 & 팁

찍기의 기대값 (오답 −0.4)

남은 선택지기대 점수판단
5개 (하나도 소거 못 함)1.5×0.2 − 0.4×0.8 = −0.02비워두기
4개 (1개 소거)1.5×0.25 − 0.4×0.75 = +0.075찍어도 됨
3개 (2개 소거)1.5×0.33 − 0.4×0.67 ≈ +0.23반드시 찍기
2개 (3개 소거)1.5×0.5 − 0.4×0.5 = +0.55반드시 찍기

→ 확실한 오답을 하나라도 지울 수 있으면 찍는 게 이득이고, 전혀 모르면 비워 두세요.

시간 배분 & 풀이 순서

  • 로직 5문항은 문항당 1분 30초 안팎, 총 7~8분을 목표로 합니다. 생물·화학에 시간을 더 쓰기 위해서입니다.
  • 문장 논리처럼 바로 풀리는 문제를 먼저, 배열·계산형은 뒤로 미룹니다. 2분이 넘어가면 표시해 두고 넘어가세요.
  • 영어 지문은 질문(must be true / most weakens / flaw)을 먼저 읽고 지문을 읽습니다.
  • must / cannot / could 같은 양상 표현에 동그라미를 칩니다. 문제의 절반은 이 단어에서 갈립니다.
  • 계산형은 숫자를 끝까지 계산하기 전에 범위·어림으로 선택지를 먼저 지웁니다.

공부 방법

  • 2011–2022 Cambridge 기출의 로직 문항도 유형 연습용으로 아주 좋습니다(문항 수가 많아 양이 충분).
  • 오답노트는 “왜 틀렸나”를 함정 유형(역의 오류, 퍼센트 덧셈, 단순 평균 등)으로 분류해서 기록하세요.

5. 예상문제 20제

실제 시험처럼 문항당 약 1분 30초. 20문항을 30분 안에 풀어 보세요. 정답과 해설은 뒤쪽에 있습니다.

1문장 논리 · 부정

“It is not true that every doctor in the hospital works at night.” Which of the following must be true?

  1. A  No doctor in the hospital works at night.
  2. B  At least one doctor in the hospital does not work at night.
  3. C  At least one doctor in the hospital works at night.
  4. D  Most doctors in the hospital work during the day.
  5. E  Every doctor in the hospital works during the day.
2문장 논리 · 필요조건

“Marco takes the bus only if it is raining.” Today Marco took the bus. Which statement is certainly true?

  1. A  It was raining today.
  2. B  It was not raining today.
  3. C  Whenever it rains, Marco takes the bus.
  4. D  Marco never walks to work.
  5. E  Nothing can be concluded.
3문장 논리 · 대우

“If a patient has a fever, the patient is given paracetamol.” Which statement is logically equivalent?

  3. C  If a patient is not given paracetamol, the patient has no fever.
  4. D  A patient either has a fever or is given paracetamol.
  5. E  Only patients with a fever are given paracetamol.

6. 정답 & 해설

1정답 B문장 논리 · 부정

“모든 X가 Y이다”의 부정은 “적어도 하나의 X는 Y가 아니다”입니다. ‘아무도 ~하지 않는다(A)’는 지나치게 강한 진술이라 함정입니다.

2정답 A문장 논리 · 필요조건

“Q only if P” = Q → P (P는 필요조건). 버스를 탔으므로(Q) 비가 왔다(P). C는 역(P → Q)이라 확정할 수 없습니다.

3정답 C문장 논리 · 대우

P → Q와 동치는 대우 ¬Q → ¬P 뿐입니다. A·E는 역, B는 이(裏)로 동치가 아닙니다.

4정답 A삼단논법 · 집합

벤 다이어그램: 심장내과의 ⊂ 의사, 의사 ∩ 약사 = ∅ → 심장내과의 ∩ 약사 = ∅.

5정답 A배열 추론

C=3 고정. D는 끝이 아니므로 2 또는 4, E는 4 또는 5. A-B 연속 쌍은 (1,2) 또는 (4,5)인데 (4,5)면 E 자리가 없음 → A=1, B=2, D=4, E=5.

6정답 C수열

차이가 4, 6, 8, 10 → 다음 차이 12. 또는 n(n+1): 6×7 = 42.

7정답 D수열

규칙: ×2 − 1 (차이 2, 4, 8, 16 → 다음 32). 33 + 32 = 65.

8정답 C비율 · 퍼센트

1.2 × 0.8 = 0.96 → 4% 감소. 연속 퍼센트 변화는 더하지 말고 곱합니다.

9정답 B작업량

시간당 1/6 + 1/3 = 1/2 → 2시간. 빠른 펌프(3시간)보다 짧아야 하므로 C~E는 즉시 소거.

10정답 C나이 문제

M = 3S, M + 12 = 2(S + 12) → 3S + 12 = 2S + 24 → S = 12, M = 36. 선택지 대입(역산)이 더 빠를 때가 많습니다.

11정답 C비례 · 의학 맥락

하루 총량 15 × 18 = 270 mg → 3회 분할 = 90 mg. E(하루 총량)는 단계 생략 함정.

12정답 A확률

3/5 × 2/4 = 6/20 = 3/10. B(9/25)는 복원추출로 착각한 함정.

13정답 C자료 해석

합 600 ÷ 4 = 150. 증가율: 1→2월 25%, 2→3월 20%, 3→4월 감소 16.7%. 절대값이 같아도(30명) 기준값이 다르면 %가 달라집니다.

14정답 B비판적 사고 · 오류

상관관계 ≠ 인과관계. 녹차를 마시는 사람이 운동·식단 등 다른 건강 습관을 가졌을 수 있습니다(교란변수).

15정답 B비판적 사고 · 약화

같은 시기 다른 원인(대체 원인)의 존재가 인과 주장을 가장 약화. C는 오히려 강화, A·D·E는 무관.

16정답 C요일 계산

3월은 31일 → 31 mod 7 = 3 → 화요일 + 3 = 금요일.

17정답 A진실·거짓 퍼즐
