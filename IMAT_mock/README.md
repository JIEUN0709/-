# IMAT 모의고사 10회분

2023–2026 IMAT의 **시험 형식과 출제 범위·유형 경향**을 참고해 새로 작성한 모의문제입니다.
실제 기출문항을 옮겨 적거나 바꿔 쓴 것이 아니라, 같은 형식과 난이도를 목표로 직접 만든 문항입니다.

## 시험 구성 (2023–2026 공통)

| 영역 | 문항 수 | 문항 번호 |
|---|---:|---|
| Reading skills & general knowledge | 4 | 1–4 |
| Logical reasoning & problem solving | 5 | 5–9 |
| Biology | 23 | 10–32 |
| Chemistry | 15 | 33–47 |
| Physics & Mathematics | 13 | 48–60 |
| **합계** | **60** | 100분 |

- 채점: 정답 **+1.5**, 오답 **−0.4**, 무응답 **0** (만점 90점)
- 각 문항은 보기 A–E 중 정답 1개 (회차마다 정답이 A–E에 12개씩 고르게 분포 → 찍기로는 점수가 오르지 않음)
- 계산기 사용 불가 → 모든 계산 문항은 손계산이 가능하도록 수치를 맞췄습니다.

## 2023–2026 출제 경향 메모 (작성 시 반영한 부분)

- **Reading/GK**: 짧은 과학·사회 지문의 추론 문제, 그리고 역사·문화·시사 일반상식이 섞여 나옴.
- **Logic**: 삼단논법·가정 찾기, 순서 배열, 비율·속도 문제, 숫자 규칙.
- **Biology**: 세포·분자생물학(복제·전사·번역, 세포 호흡), 유전(멘델·반성유전·가계도), 인체 생리(신경·내분비·순환·신장), 생화학 거대분자 비중이 높음.
- **Chemistry**: 몰 계산·화학양론, 산화수/산화환원, pH·완충, 주기율 경향, 결합·분자구조, 유기 작용기와 이성질체.
- **Physics & Math**: 역학(운동·힘·에너지), 전기회로, 유체·열, 파동, 그리고 대수·로그·삼각함수·확률.
